# extension/
> L2 | 父级: ../CLAUDE.md

config.js: 宿主名、GSC 文案规则与等待时间，维护者的可定制入口之一。
manifest.json: 声明工具栏入口、扩展公钥、最小权限与 GSC 站点权限。
worker.js: 将点击的标签页绑定到本机连接，报告版本，整页打开目标资源，按本机配额阻止提交，绑定页关闭后断开。
property.js: 当前资源覆盖网址时直接使用，否则多种方式展开资源列表并按主机名逐级筛选，选最具体的资源，不点击选项。
submit.js: 按模式读取报告、跳过已收录项或请求重抓，点击当前可点的按钮，控件被遮挡时停下，DOM 变化驱动等待。
page.test.js: 用 jsdom 模拟页面验证注入函数。

[PROTOCOL]: 变更时更新此头部，然后检查 CLAUDE.md
