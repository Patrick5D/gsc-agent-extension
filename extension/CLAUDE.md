# extension/
> L2 | 父级: ../CLAUDE.md

config.js: 宿主名、自动连接开关、GSC 文案规则与等待时间，维护者的可定制入口之一。
manifest.json: 声明工具栏入口、扩展公钥、最小权限与 GSC 站点权限。
worker.js: 默认自动连接本机，选用已打开的 GSC 标签页或后台新开，点击图标固定到当前页；报告版本，整页打开目标资源，按本机配额阻止提交。
property.js: 当前资源覆盖网址时直接使用，否则多种方式展开资源列表并按主机名逐级筛选，选最具体的资源，不点击选项。
submit.js: 只读最新一份报告，返回收录状态与未收录原因，跳过已收录项或请求重抓，点击当前可点的按钮，控件被遮挡时停下，DOM 变化驱动等待。
page.test.js: 用 jsdom 模拟页面验证注入函数。
worker.test.js: 用模拟的 chrome 接口验证自动连接、选页、点击固定与断线重连。
